# AnimeHub Free Demo

## Phone/PC par chalana
1. Is folder ki files ek hi folder me rakho.
2. `index.html` ko browser me open karo.
3. Search aur genre buttons try karo.

## Online free deploy
GitHub Pages ya Cloudflare Pages par is project ko deploy kiya ja sakta hai.

## Important
Demo me fictional anime names hain. Kisi copyrighted anime/episode ko bina permission upload ya distribute mat karo.
